# Referencias observadas

Cinco capturas originales de los ZIP Wiser aportados por el usuario, conservadas sin modificar. Se revisaron sus formas, recortes, tipografía y doblez para preparar los prompts. Las generaciones nuevas usan una descripción de esos rasgos; las ediciones de Fermat, Platónico y Cebras también usan una captura como referencia visual directa. Las capturas no son portadas nuevas ni instrucciones de trabajo.

Los dos ZIP completos y sus 122 capturas únicas permanecen en la carpeta de referencias Wiser y en GitHub.
